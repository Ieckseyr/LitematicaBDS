# 命令

`/litematica`，别名 `/lit`。多数命令需要玩家身份。

## 投影

| 命令 | 说明 |
| ---- | ---- |
| `list` | 列出 `schematics/` |
| `load <名字>` | 加载并校验 |
| `place [名字] [x y z]` | 放置，默认脚下；也接受 `place <x> <y> <z>` |
| `placeat <x y z> [名字]` | 指定坐标放置（LeviLamina） |
| `clear` | 清除并还原假方块 |
| `layer all` | 全部显示 |
| `layer slice` | 只显示玩家**脚部**坐标所在单层 |
| `layer auto` | 脚部上下各 2 层 |
| `layer <n>` | 手动固定局部层号 |
| `layer next/prev` | 手动翻层 |
| `rot <0/90/180/270/next>` | 旋转 |
| `mirror <none/x/z/xz/next>` | 镜像 |
| `info` | 当前投影状态 |

## 选区与保存

- `pos1` / `pos2`：设角点。两点齐全后显示盒线框 + 尺寸/体积/角点悬浮字（RGB 循环色）。
- `save <名字> [x1 y1 z1 x2 y2 z2]`：保存为 `schematics/<名字>.litematic`；
  无坐标时用 `pos1/pos2`，无选区时用当前投影包围盒。
- `materials [数量]`：材料 CSV 到 `exports/`。

保存体积受 `save.maxVolume` 限制（默认 262144 = 64³），重名拒绝。

## 硫磺怪与填充（LeviLamina）

进入 `sulfur.radius`（默认 8）格后：

- 实心方块变成硫磺怪，主手含着对应方块（`sulfur.visible=false` 时本体隐身，只看到方块）；
- 方块外包一层 DebugShape 框；
- 非方块投影保留完整状态假方块 + 框，不生成硫磺怪；
- 玩家可穿过；
- 手持对应方块**左键（攻击）**点击 → 先扣除 1 个，再放置真实方块；
- 生存消耗 1 个（`fill.consumeItem`），创造不消耗；放置失败会退还；
- `fill.quickFill=true`（默认关闭，管理员）时，手持**木棍左键**点击硫磺怪：
  从背包缓存池自动找对应方块，先扣除再填充；缓存每 100 tick 或扣除失败时刷新；
- `fill.requireOp=true` 时普通填充也仅 OP 可用；
- 成功放置后立即移除框和硫磺载体；
- 非方块投影（花草/火把/铁轨等）只画框，不生成硫磺载体；
- 离开半径后销毁框/载体，方块保持显示。

左键**直接点投影方块**也可以填充，不要求先变成硫磺怪；框同样在成功后移除。

## 菜单

手持**木棍右键**打开；**木棍左键**快速放置当前已选投影。OP 额外有管理员菜单。菜单包含放置/加载、分片/自动/全部/翻层/手动层号、旋转、镜像、
材料、保存、选区、信息、状态、重载；OP 额外看到管理员菜单。

## 管理

- `reload`：重读配置与原理图（OP）。
- `status`：运行状态。

## 管理员配置表单

OP 主菜单的“管理员菜单”是 `CustomForm`，可直接调整：

- 渲染：每 tick 方块数、视距、自动层半径、单玩家上限、重规划阈值、只显示暴露面
- 硫磺怪：半径、上限、启用、显示本体、跟随朝向
- 填充：启用、需要 OP、消耗物品、快速填充
- 保存体积上限、投影包围盒颜色、默认旋转/镜像
- 原理图/导出目录、调试日志

提交后立即写回 `config.json`，应用新配置并触发在线投影重规划。
